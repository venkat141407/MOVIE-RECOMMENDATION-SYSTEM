# 🎬 AI Movie Recommendation System

An AI-powered Movie Recommendation System built using Flask and Machine Learning.

## Features

- User Registration & Login
- AI Movie Recommendations
- Favorites
- Watchlist
- Movie Search
- Autocomplete
- OMDb API Integration
- Responsive Netflix-style UI

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- SQLAlchemy
- Pandas
- Scikit-learn
- MovieLens Dataset
- OMDb API

## Installation

```bash
git clone https://github.com/USERNAME/AI-Movie-Recommendation-System.git
cd AI-Movie-Recommendation-System
pip install -r requirements.txt
python train.py
python app.py
```

Open:

```
http://127.0.0.1:5000
```
